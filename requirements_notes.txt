Notes:
- memote 0.13 with the installed COBRApy stack required a numpy.object monkey patch.
- Chinese paths can make memote report inputs unreadable, so the validation scripts copy
  SBML files to ASCII-only temporary paths before running memote.
- CPLEX Community Edition can hit size limits for direct model optimization; GLPK was
  used for basic final model solve checks.
